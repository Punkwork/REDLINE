# SAMIZINE boards (ZINE-003)

The underworld's zine look: punk zine attitude, samizdat materials. Spec: `docs/REDLINE_SAMIZINE.md`.

- `01-style-sheet.png` … `05-copy-generations.png`: the five boards, rendered at 1.5×.
- `samizine-review.pdf`: the same five boards as the designer's review PDF (v3, 2026-11-18).
- `canvas/`: sources of the live design canvas (https://claude.ai/artifact/G84PwRDUPwMSvAYkBxmudW). Each `.dc.html` is one board in the Design canvas format; it needs the canvas runtime (`support.js`) to open as-is. The canvas is the editable original; these copies are a snapshot.

Fonts used: Special Elite, Stardos Stencil, Permanent Marker, Poiret One, Space Mono, DM Sans (Google Fonts; licences in `godot/assets/fonts/` once added).

# CARDS-005 / CARDS-005a — Corner icons (APPROVED and built, 2026-11-19)

The icons stack down each card's top-right corner, most important first:

1. Icepick type (FORTRESS, TUMBLER, VOID, or an asterisk for ANY).
2. RAM on PROGRAMs.
3. TRACE or CRED cost.
4. Target.

**CARDS-005a** turns them into hardware: round indicators set into a steel rail, so they read as part of the cartridge. BLOATWARE gets a "can't be played" indicator, and a red TRACER +3 penalty lamp where it applies. An unplayable card's cost dial shows "—".

- `CARDS-005_Corner_Icons_First_Pass.jpg`: flat plates (replaced).
- `CARDS-005a_Hardware_Corner.jpg` and `CARDS-005a_Hardware_Corner_3x.jpg`: the built hardware rail, at 1× and 3×.
- `CARDS-005a_Bloatware_Current_vs_Proposed.jpg`: BLOATWARE before and after.

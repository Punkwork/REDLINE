# ENC-CONCEPT-001 — ChatGPT prompts, round 4 (the other Node types and the map)

**Date:** 2026-11-20 · **Author:** Claude · **For:** the designer, to paste into ChatGPT
**Why:** the designer asked what else ChatGPT can make in the meantime, "at least for the other node types". Core Rules §10 lists the Node types: ICE (covered by round 3's corporation backgrounds), Uplink, SAFEHOUSE, DEAD DROP, Console Lab, SIGNAL UNCLEAR, the Central Node, the escape, plus the map that shows them.

**Two worlds, one style.** Corporate places (Central Node, escape, map) use the corporation's palette and emblem (AVATAR-001 §2.1). Rustler places (Uplink, SAFEHOUSE, DEAD DROP, Console Lab) are the underworld: the same painted 1950s atompunk style, but salvaged, hand-patched, lived-in, warm tungsten light, tape and stencilled shapes. Never any words in the art, so the copy guards stay with the game's own text (no "Archipelago", only ’Pelago in Rustler copy; nothing else needs checking in pictures with no text).

How to use: one ChatGPT conversation per prompt, attach the references, paste once, type **next** after each image, save each with its exact file name into `PANOPTICON art`. Wiring these in is a Claude Code task once they arrive (see HANDOFF).

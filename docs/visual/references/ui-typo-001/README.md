# UI-TYPO-001 reference images

The designer's four reference images for **UI-TYPO-001**, the dual visual language (Master Design, UI-TYPO-001; UI Design Bible §2a; GitHub issue #24). Added 2026-11-25.

**What they show:** the **virtual world** as **event flyout titles**: big, angled, neon title cards (RUNNER TURN, CORPORATION RESPONSE, DEADLOCK BREACHED and others) that sweep across the **physical world**, the 1950s Atomic Deco Punk console, which stays unchanged underneath. The images credit Atomic Deco Punk with influences from Gaspar Noé and Tom Kan.

| File | What it shows |
|---|---|
| `UI-TYPO-001_01_Aggressive_Flyouts.png` | Experimental, aggressive treatment: layered collage, halftone, film grain, stretch-and-glitch exit. Four-step animation (enter 0–0.15 s, build 0.15–0.30 s, hold 0.30–1.20 s, exit 1.20–1.50 s). |
| `UI-TYPO-001_02_Refined_Flyouts.png` | Refined version for frequent events: simpler and quicker so it doesn't tire the eye; the same layout and timing every time. Four steps (enter 0–0.12 s, reveal 0.12–0.25 s, hold 0.25–1.10 s, exit 1.10–1.30 s). Palette by event: RUNNER TURN cyan (frequent, energetic, clear), CORPORATION RESPONSE red (frequent, threatening), DEADLOCK BREACHED magenta and gold (less frequent, high impact). |
| `UI-TYPO-001_03_Title_Announcements.png` | Prototype system: Atomic Deco Punk with neon title design, three example events and a 1.5 s animation (enter, reveal, hold, exit). A non-destructive overlay: the HUD itself is unchanged. |
| `UI-TYPO-001_04_Event_Typography_Catalogue.png` | Catalogue of twelve event title styles: Runner turn, Corporation response, ICE encounter, TRACE increase, DEADLOCK breached, Extraction, Full extraction bonus, Damage taken (PULP), Synaptic damage, Neural damage, Program installed, ICE strength change. |

**These are style references, not rules.** Several labels predate the current rules and must not be built as written:
- **SYN / Synaptic damage** and **Neural damage**: SyN was removed in the Core Rules redesign (§6); a DISCARD effect is what's left.
- **Full extraction bonus +10% CRED**: removed by CORE-012.
- **"Runner"**: the player is a **Rustler** now.

Values shown (TRACE +4, +25 CRED, PULP −3, STR +1) are illustrative. Real flyouts take their text and numbers from engine state.

**Resolution:** these copies are 640 × 360 (the catalogue 640 × 427), the size they arrived at. Higher-resolution originals can replace them under the same names.

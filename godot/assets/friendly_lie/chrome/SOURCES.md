# Chrome Deco prototype assets

Generated with OpenAI image generation on 2026-11-17 for the designer-authorized CHROME-001 visual experiment. These are prototype illustrations, not designer-approved final art.

- `atrium.png`: architectural background derived from the designer's preferred Chrome Deco concept. No UI is baked into it.
- `atrium-hostile.png`: generated edit of the exact atrium, revealing observation galleries, cameras and processing rails; clean architecture is preserved.
- `auto-renew-shell.png`, `captcha-shell.png`: transparent empty appliance shells. Face parts, text, buttons and rule state are live Godot controls.
- `toner-illustrations.png`: six-cell monochrome illustration atlas, sampled at runtime using AtlasTexture. Motifs are reused by semantic card role as prototype art; no card rules are baked into it.

Source PNGs remain in the workspace's generated_images directory. No gameplay data or font licensing is changed.
